Видеоповторы

  1. Система видеоповторов, встроенная в табло, может работать с различными источниками видеосигнала - IP-камерами, смартфонами, web-камерами и т. п.
  2. Для работы со смартфоном надо установить на него программу "IRL Pro" (из "Google Play") и программу "Автонастройка камер" (.apk файл находится в каталоге с программой табло). Подробности настройки и работы с видеоповторами см. в видеоинструкции по работе с видеоповторами (находится в каталоге с программой табло).
  3. Рекомендуемые требования к оборудованию для работы с web-камерами:
    • Компьютер с процессором Intel Core i7;
  4. Оборудование, с которым тестировалась программа на текущий момент:
    • Веб-камеры - ACD Vision UC500;
    • USB-разветвитель DEXP PREMIUM M3H4-G2-OG;
    • Кабель удлинитель USB GCR.
  5. Для работы с веб-камерами, надо выбрать нужную камеру из выпадающего списка, затем выбрать параметры камеры. Если камеры были подключены после запуска программы, то сначала надо обновить список веб-камер нажатием соответствующей кнопки. Если камера поддерживает автофокус, рекомендуется отключить его и настроить вручную, вызвав меню настроек камеры в разделе "Настройка Web камер". При работе на компьютере со слабым процессором и/или не поддерживающем аппаратное декодирование видео с веб-камер (например компьютеры с процессорами AMD), возможно, придется уменьшить разрешение видео и/или частоту кадров, выбрав нужные параметры из списка. При подключении веб-камер через удлинители и usb-разветвитель не подключайте к разветвителю ничего кроме камер (например, зарядные устройства, мыши и т.п). Если для трансляции в ВК выбрана веб-камера, то не рекомендуется выбирать звук трансляции с этой же камеры!
  6. Просмотр видеоповторов производится нажатием кнопок  (просмотр с выбором файла) и   (просмотр последнего записанного файла). При просмотре видеоповтора, можно включать режим "повтор" нажатием клавиши "пробел". Увеличение масштаба видео делается колесом прокрутки мыши, при наведении на экран просмотра плеера.
