Выбор спортсменов

  1. Окно выбора спортсменов вызывается нажатием кнопки "Спортсмены". Далее выбираются (если ещё не выбраны) возрастная и весовая категории.
  2. Выбираются спортсмены нажатием левой кнопкой мыши по ячейке в основной (левой) таблице. Если в таблице отображается много спортсменов, то для упрощения выбора можно вводить начальные буквы их фамилий в поле "фильтр по фамилии". При этом в таблице будут показаны только спортсмены, фамилии которых начинаются на эти буквы. При наличии времени, желательно выбрать как можно больше спортсменов, согласно протоколам.
  3. Если в файле со списком присутствует пятый столбец с номерами, то спортсмена можно выбрать вводом его номера.
  4. Выбранные спортсмены отображаются в правой таблице. В зелёном поле слайдера находится вызываемая пара спортсменов, в жёлтом - готовящаяся. Для следующих боёв слайдер надо сдвигать вниз с помощью левой кнопки мыши. Удалить спортсмена из этой таблицы можно нажатием правой кнопки мыши на ячейку. Также, левой кнопкой мыши можно перетаскивать ячейки между собой (нельзя перетащить или удалить ячейки, находящиеся в слайдере).
  5. Выбранные спортсмены не отображаются в основной таблице, поэтому периодически надо очищать правую таблицу, нажатием кнопки "удалить отработанные фамилии" или кнопки "удалить всех". Если произошёл сбой программы и в слайдере неправильно отображаются фамилии спортсменов, то надо очистить таблицу нажатием кнопки"удалить всех".
  6. Если в списках не хватает спортсмена(ов), то нажатием кнопки "Добавить спортсмена", вызывается окно добавления или выбора спортсмена. После ввода фамилии и региона (команды) в соответствующих полях, надо нажать кнопку "Добавить". Добавленные спортсмены выбираются из нижнего списка нажатием левой кнопки мыши. Так как эти спортсмены остаются в памяти программы, то при следующих соревнованиях, список надо очистить нажатием кнопки "очистить список".
  7. Для удобства работы с окном выбора спортсменов, можно настроить размеры шрифтов таблиц и высоту слайдера с помощью соответствующих элементов управления в верхней части окна.
