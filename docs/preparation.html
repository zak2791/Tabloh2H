Подготовка файла со списком спортсменов

Создать Excel файл (формат .xlsx) в любом каталоге. Файл должен содержать столбцы с фамилией спортсмена, названием команды (региона), возрастной категорией и весовой категорией. Если нужен выбор по номерам, то надо добавить пятый столбец с номерами спортсменов. Таблица не должна содержать пустых строк. После открытия программы, выбрать файл из меню "файл".
